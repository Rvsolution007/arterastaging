# Artera – Agent Entry Rules

Before changing this workspace, read and follow the complete project policy in
`.agents/AGENTS.md`. That document contains the locks, source-of-truth rules,
and the mandatory render-version contract governance policy.

## Render-version non-negotiable

`render_version` is a data contract. A request to create, modify, upgrade, or
downgrade V11–V25 (or any later version) is never a number-only renderer
switch. Follow the **Render-Version Contract Governance (V10–V25+)** section
in `.agents/AGENTS.md` before writing code or data.
